# Budget-Pro
Built a fully AI-generated Budget Tracker web app using HTML, CSS, and JavaScript. Developed with AI assistance, it tracks planned vs actual expenses, visualizes data using Chart.js, supports CSV export, and uses localStorage for real-time updates and persistence.
💰 Budget Tracker Web Application

A modern and responsive Budget Tracker Web App built using HTML, CSS, and JavaScript, designed to help users manage their monthly expenses efficiently with real-time insights and visual analytics.


---

🚀 Features

📊 Expense Tracking

Track Planned vs Actual expenses

Predefined categories:

Grocery, Vegetables, Medicine, Mobile Recharge, Milk, Rice, Cable, Other, Current Bill, Savings, Emergency


Mark each expense as:

✅ Done

⏳ Pending




---

📈 Data Visualization

Interactive charts powered by Chart.js:

Bar Chart → Compare planned vs actual spending

Doughnut Chart → Category-wise expense distribution


Real-time updates without page reload



---

💾 Data Persistence

Uses localStorage

Data remains saved even after refresh or reopening browser



---

📁 Export Functionality

Download budget data as CSV file

File includes:

Category

Planned amount

Actual amount

Status




---

🔔 Notifications

Toast notification system:

✔ Success messages

⚠ Alerts (e.g., overspending)


Auto-dismiss after a few seconds



---

🎨 UI/UX Features

Clean and modern dashboard design

Fully responsive (mobile + desktop)

Dark/Light mode support

Smooth animations and fast updates
